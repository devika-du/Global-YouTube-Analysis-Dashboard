## 📌 Project Overview

This project analyzes global YouTube data to understand video performance, audience engagement, and trends across different countries and categories.

The dashboard was created using **Power BI** to transform raw data into interactive visual insights that help identify patterns in views, likes, comments, and video performance.

## 🛠️ Tools Used

* **Power BI**
* **Power Query**
* **DAX**

## 📂 Dataset

The dataset contains global YouTube video information, including details related to:

* Country
* Category
* Video views
* Likes
* Comments
* Video performance
* Other engagement-related metrics

## 🧹 Data Preparation

The data was prepared using **Power Query** before creating the dashboard.

Key steps included:

* Handling missing and inconsistent values
* Removing unnecessary data
* Checking data types
* Cleaning categorical fields
* Preparing the data for analysis

## 📊 Dashboard

The Power BI dashboard provides an interactive view of global YouTube performance.

### Key Analysis

* Global video performance
* Views and engagement analysis
* Country-wise comparison
* Category-wise performance
* Trends and patterns in YouTube data

## 💡 Key Insights

* Identified countries with higher YouTube activity and engagement.
* Compared video performance across different categories.
* Analyzed the relationship between views and audience engagement.
* Identified major patterns and trends in global YouTube data.

## 🎯 Project Objective

The main objective of this project was to practice **data cleaning, data visualization, and analytical thinking** using a real-world dataset and present the findings through an interactive Power BI dashboard.
